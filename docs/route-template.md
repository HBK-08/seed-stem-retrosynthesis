# 单题工作稿

**目标与题面约束**　附原始结构图，记录核对后的 SMILES、明确或未指定的立体中心、允许的起始原料和题面特别要求。

**方舟原始回答**　记录日期、模型、提示词、回答文件或会话位置及用时。如人工修正了读图结果，写出修正前后的差异。

**断键选择**　写出首选断键和前体，解释该选择如何解决骨架构建、官能团兼容性或立体控制问题。若有可行替代路线，写明哪项证据会改变选择。

**首要不确定性**　写清最可能失败的步骤、可观察的竞争产物，以及哪条实验先例或分析数据能够区分它们。

**提交草稿**　从起始原料正向串起完整路线，列明哪一步决定区域或立体选择性、哪一步限制验证可行性。按当届要求附图和来源。
